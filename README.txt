MY WORKOUT PLANNER — ANDROID PWA

Included: current phone-optimized workout planner, app manifest, service worker, and 192/512px icons.

Publish the contents of this folder to an HTTPS static host, then visit that HTTPS URL in Chrome on Android and choose Install app. See INSTALL_ON_ANDROID.txt.

Your plans and logs are stored locally in Chrome on that device. Export backups regularly. This package does not yet enable account-based cloud sync or server-side paid access.
